# Suggested meaningful Git commit history

Make these commits as you build/test the project; do not create one final snapshot commit only.

1. `chore: add PHP project structure and documentation`
2. `feat: build responsive visitor registration and upload form`
3. `feat: add visitor identity and photo upload validation`
4. `feat: add admin photo moderation dashboard`
5. `feat: add auto-refreshing public slideshow`
6. `docs: document privacy consent assumptions and manual tests`
7. `feat: migrate persistence layer and schema from SQLite to MySQL`
8. `docs: add XAMPP MySQL setup and verification steps`

For the submitted repository, make commits during actual work and do not fake timestamps or claim these commits already exist.
